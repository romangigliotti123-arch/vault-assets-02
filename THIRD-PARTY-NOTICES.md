# Third-party notices

The zip files in the Releases of the `vault-assets-NN` repositories contain only material that its authors published under a licence that allows redistribution: Apache-2.0 (3 packs), CC0-1.0 (63 packs), MIT (33 packs), MPL-2.0 (5 packs). Nothing else is included. Every pack keeps its own licence file inside the zip (`License.txt` / `LICENSE` at the top of the pack folder, `SOURCE.md` for the download source); the licence texts are also copied to [`licenses/`](licenses/) in this repository.

## What each licence asks of you

- **CC0 1.0** (Kenney, Quaternius, Poly Haven, ambientCG, one example game): public-domain dedication, no conditions. Credit is appreciated, not required.
- **MIT**: keep the copyright notice and licence text with copies of the code. They are in each pack folder and in `licenses/`.
- **Apache-2.0** (ProfileService, ProfileStore, rice-simulator): keep the licence and notices, state changes. The LICENSE file in the pack folder is the licence text.
- **MPL-2.0** (Lune, Rojo, Selene, StyLua, Wally): file-level copyleft: if you change a file of these projects and distribute it, publish that file under MPL-2.0. The source in the zip is the upstream source.

Some packs bundle smaller upstream components with their own notices (for example `code/Luau/extern`, `code/luau-lsp/extern`, benchmark files in `code/Luau/bench`, Nevermore sub-packages). Their licence files stay in place inside the zip. `code/Zap` documentation names an icon from Twemoji (c) Twitter, Inc., CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/). The voice packs `audio/kenney-voiceover-pack*` are credited in their `Credits.txt` (voice actors Jeffrey M. Smith and Giselle); Kenney publishes them under CC0.

## Left out on purpose

- Anything whose licence is unknown, non-commercial (NC), no-derivatives (ND), paid, ripped from a game, or owned by Roblox/another game publisher.
- `rbx_binary/benches/files/miners-haven.rbxl` from the rbx-dom project: place file of a third-party Roblox game, removed from `code.zip` before publishing.
- `.env` of `code/game-factorial-defence` and `util/Certificates.p12` of `code/studio-rust-mcp-server` (credential-style files, not needed), removed from `code.zip`.
- Roblox Creator Store items and Roblox's own game screenshots/footage. This repository has none.
